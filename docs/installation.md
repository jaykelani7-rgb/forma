# Daily access and offline behavior

Forma provides a standalone web manifest, 192/512-pixel PNG icons, a maskable icon and an Apple home-screen icon. Install it from a supporting browser's address bar/menu. On iPhone or iPad, use Safari → Share → Add to Home Screen. Use HTTPS for a hosted installation; localhost also supports local development. Browser eligibility and prompts vary. These conventions follow the [Next.js PWA guide](https://nextjs.org/docs/app/guides/progressive-web-apps) and [MDN installability guidance](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable).

The service worker deliberately caches only the static reconnect page, fonts and icons. It never stores API responses, credentials, page HTML or notebook records in a shared application cache. IndexedDB holds local records, including active-session notes, through the workspace persistence layer. An already loaded tab can continue local practice when the connection drops. A fresh offline launch receives a reconnect page rather than a partially cached application. Codeforces imports, uncached discovery and account sync need a connection. Full cold-launch offline practice is not implemented.

Updated workers wait for an explicit action or for all old pages to close. The update notice requires the active session to finish and pending local writes to settle before activation. Activation never reloads any tab: drafts and unsynced notes stay open. Reopen Forma after finishing work to load new application code. The worker deletes only its own previous public-resource cache. It does not touch IndexedDB or other apps' caches. See [MDN service-worker lifecycle](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers).

Settings offers an opt-in in-app reminder, disabled by default. It uses the device's local time, appears only on Today while Forma is open, and stays quiet after a completed timed session or imported submission has been recorded for that day. It also stays quiet during an active session. Dismiss it for today or disable it in Settings. It does not request notification permission and cannot deliver notifications with the app closed. No push service or recurring server scheduler is configured.

Regression tests exercise manifest/icon dimensions, the service-worker public-resource allowlist, credential/API bypass, offline fallback, deliberate update activation and reminder scheduling. Device installation and closed-app notification delivery are not asserted by these tests.
